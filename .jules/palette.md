## 2024-05-24 - Search Input UX and A11y enhancements
**Learning:** Adding a clear button within custom search inputs significantly improves usability, but doing so requires properly assigning `aria-label` attributes to both the input itself and the clear button so screen readers convey intent accurately. Additionally, utility classes like `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background` are essential for these custom inputs and their inner buttons to maintain keyboard navigation visibility.
**Action:** Always include an `aria-label` for screen reader context on text inputs that lack a visible `<label>`. Ensure any interactive element inside an input wrapper, such as a clear or search button, is keyboard accessible by adding appropriate `focus-visible` styles and a descriptive `aria-label`.
