## 2026-04-02 - Native Confirmation Dialogs for Bulk Actions\n**Learning:** Destructive bulk actions (like 'Clear All' for history/downloads) in desktop apps require safe friction to prevent accidental data loss, as these actions are often unrecoverable.\n**Action:** Use native browser `window.confirm` for simple destructive actions to minimize plugin overhead when adding UX friction, avoiding the need for heavy Tauri plugins for simple boolean checks.
