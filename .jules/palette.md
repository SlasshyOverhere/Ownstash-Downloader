## 2024-03-21 - Custom Interactive UI Element Accessibility
**Learning:** Custom interactive UI elements in this repository (e.g., custom Toggles, tabs, or radio groups built from divs/buttons) often lack proper ARIA roles and dynamic states out-of-the-box. Additionally, they require manual implementation of specific `focus-visible` utility classes for keyboard navigation.
**Action:** When working with or creating custom interactive components (like `role="tablist"` or `role="radiogroup"`), always manually implement their corresponding roles, dynamic states (like `aria-selected` or `aria-checked`), and add `outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background` utility classes. Visual indicators should be explicitly hidden from screen readers using `aria-hidden="true"`.
