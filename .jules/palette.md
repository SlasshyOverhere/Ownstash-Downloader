## 2025-04-04 - Native Window Confirm Dialogs for Destructive Actions
**Learning:** Native `window.confirm` provides an immediate, accessible, and lightweight way to add safety rails to destructive actions (like clearing all downloads or search history) without introducing heavy UI dependencies or complex React state. It automatically handles focus and keyboard accessibility for the dialog itself. However, it blocks the main thread, which requires specific mocking or bypassing strategies when writing automated UI tests with Playwright (e.g., using `page.on("dialog", handler)`).
**Action:** When implementing micro-UX improvements involving confirmation for destructive actions within strict size/complexity constraints, prioritize `window.confirm` over custom modal components. For automated visual testing of the trigger elements, use `.focus()` to capture the element state without triggering the blocking dialog, or set up a dialog handler before clicking.
