## 2024-03-29 - Missing React.memo for use3DTilt usage
**Learning:** High-frequency interaction hooks like `use3DTilt` cause parent components to re-render constantly. Wrapping the parent or moving the hook into a smaller memoized component reduces unnecessary rendering. The `use3DTilt` hook internally triggers `requestAnimationFrame` and state updates (`setTilt`) on `mousemove`. When `use3DTilt` is used in a large component without memoization, every mouse movement triggers a re-render of the *entire component* (e.g., `QuickStat` inside `HomePage`).
**Action:** Always wrap components using high-frequency interaction hooks (like `use3DTilt`) with `React.memo` to isolate re-renders, and use `useCallback` for props passed to them, or mutate the DOM imperatively inside the hook without state.
