## 2024-05-24 - React Render Cycle Bottleneck in High-Frequency Animation Hooks
**Learning:** Using `useState` to drive rapid, high-frequency animations (like mouse tracking in `use3DTilt`) can trigger excessive component re-renders. When these components are deeply nested or contain complex children, this leads to significant performance bottlenecks and main thread blocking.
**Action:** When implementing high-frequency animations tied to user input (like mousemove or scroll), bypass the React render cycle entirely. Instead, use a `useRef` to maintain a reference to the DOM element and directly mutate its style (e.g., `ref.current.style.transform`). Ensure the imperatively mutated properties are not also defined in the component's React `style` prop to prevent React from overwriting them during unrelated renders.
