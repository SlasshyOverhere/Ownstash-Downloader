## 2024-03-30 - High-Frequency State Updates in Animation Hooks (use3DTilt)
**Learning:** In React, updating state on high-frequency events like `mousemove` causes excessive re-renders, even when wrapped in `requestAnimationFrame`. If the state is only used to compute DOM styles (e.g., transform properties for an animation effect like a 3D tilt) and doesn't affect other React logic, React's render cycle becomes a performance bottleneck.
**Action:** When creating hooks or components for high-frequency DOM manipulation (like mouse tracking), bypass the React render cycle entirely by omitting `useState`. Instead, use a `useRef` to maintain references to both the DOM element and the internal animation state, and directly mutate the element's style properties (e.g., `ref.current.style.transform`) within the `requestAnimationFrame` loop.
