## 2024-05-24 - Arbitrary Code Execution via Frontend-Supplied Paths in Command::new()
**Vulnerability:** The `open_with_external_player` Tauri command accepted a `player_path: Option<String>` directly from the frontend and passed it unchecked to `Command::new()`. This allowed Arbitrary Code Execution (ACE) as the frontend could supply any executable path (e.g., cmd.exe, bash) and argument via `file_path`.
**Learning:** Using `std::process::Command::new()` with user-provided executable paths in Tauri commands is a critical ACE vector. Even if you check `Path::exists()`, relative paths or absolute paths to system shells can bypass intent. Simple filename allowlists break custom player functionality.
**Prevention:** Executable paths should be resolved securely from backend configuration (e.g., via `state.db.lock().unwrap().get_setting()`) rather than accepted as input from the frontend. Always use the application state/database to retrieve sensitive configuration like external executable paths.
